## 状态模型（四态）
`active`（候选）/ `ineffective`（复查不生效，新增）/ `superseded`（被取代）/ `expired`（已过期/退役，人工处置）。

### 迁移表（内联；本功能自动写入，人工治理不在此限）
| 当前态 | 事件 | 新态 |
|---|---|---|
| `active` | 合格负判定（实际执行+可归属失败） | `ineffective` |
| `ineffective` | 合格负判定 | 不变（幂等自环） |
| `active`/`ineffective` | 被新条取代 | `superseded` |
| `active` | capability 改名/退役 | `expired`（允许的人工处置，非强制） |
| `superseded`/`expired` | 负判定 | 不变（终态优先） |
| 任意 | 判定=生效/不适用 | 不自动迁移 |
| 同批（负判定+取代） | 一次 retro | 取代优先（终态） |
| 任意 | 显式纠错 | 走 D3 纠错路径 |

- "未列事件"=本功能**自动写入一律不写**；现有人工治理（改标 `general`/`expired`）保留。
- 分工：writer 写时查合法迁移；lint 验收时查合法终态 + 处置。幂等=二次执行成功零 diff。

## D1 · 解析与资格
- 段落：只读唯一顶层二级段 `## 经验引用`/`## 经验警示`/`## 上次经验复查`（跳注释/围栏）。
- **ID 合约**：`exp-YYYYMMDD-<slug>`（`LESSON_NAME_RE`，`experience-lint.mjs:28`）。
- 规范行样例（合法 ID）：
  - 引用：`- [经验 exp-20261120-login-timeout] 采用`
  - 警示：`- [警示 exp-20261120-old-route] 已过时，直接替代 exp-20261120-new-route`（替代 ID 非引用）
  - 判定：`- [经验 exp-20261120-login-timeout] 判定: 不生效 — 依据 …`（`JUDGMENT_RE`）
  - 重验任务：`- [ ] [经验 exp-20261120-old-route] [重验 exp-20261120-old-route] 验证动作…`（两 ID 一致、绑一任务）
- 资格：先验**每条有效引用恰一个绑定 `[经验 <id>]` 任务**（缺/多即 fail），再以**有效引用集**（非交集）为判定期望集；负判定须带已执行证据。**形似规范行但格式错 → 报错**。
- 重验：`[重验 <id>]`（与 `[经验 <id>]` 同行同 ID）方从警示升入引用链。tasks/写入/lint/report 共用解析。
- 反例：引用有任务判定都无→fail；仅警示无任务→pass；重复标题/围栏/夹 ID/格式错/显式重验。

## D2+D3 · 处置验收表（含纠错一致）
复用 retro「经验处置」，负判定带稳定键（change + 主ID + 已审判定）：
| 处置 | 含义 | 资格 | 库状态 | 归档前 | 归档后(CI) |
|---|---|---|---|---|---|
| `已应用` | 合格负判定、本地、授权→迁 | 项目本地 | 置 `ineffective` | 记录+目标态+INDEX | 校验记录 |
| `终态无需改` | 迟到判定、目标已 superseded/expired | 任意 | 不变 | 记录+目标态合法（须验收处置、非应写状态） | 校验记录 |
| `仅记录` | 共享库/未授权根 | 共享/未确认 | 不变 | 记录（不查状态） | 校验记录 |
| `已撤销` | 显式纠错（追加列撤销键，不替换） | 项目本地 | 恢复 | 记录+目标态+INDEX | 校验撤销键 |

- **资格**：根选择结果 + store 元数据（`store_id`），且**实际经验目录确在已确认规范化本地根内、库非注册 store** 才 `已应用`；外跳/别名/冲突→`仅记录`。writer 与 lint 同判据；不靠 `kind`/`--store`。
- **纠错一致**：`已撤销` 追加列撤销键；**只要还有未撤销、要求回灌的负判定，就不能恢复 `active`**；纠错后**新**合格负判定仍须回灌。
- 反例：两负判定只撤一条 / 全撤 / 撤销后新负判定。不做新账本/审批服务。

## D4 · opt-in 与版本契约
创建后/proposal 前显式 opt-in（`x-experience-recheck-v1: true`）+ 只读能力检查（schema 协议声明 + lint 协议能力）；CI 查能力非退出码。

### 兼容矩阵（内联）
| 旧工件 + 新读取器 | 可读 |
| 旧 schema + 新 lint | 仅兼容读取 |
| **新 schema + 旧 lint（普通检查绿）** | **不得启用**（补回归） |
| 全新匹配 | 启用 |

启用后删标记仅承诺单边检测；未 opt-in 不重放、不因升级补标。探针名/输出留实现计划。

## 检索行为
`active`→引用段+任务+计指标；非 active→`## 经验警示`固定格式不展开正文；`superseded` 显直接替代者、链异常不编 ID；不一致不按 active 注入；proposal 快照建任务前复核。警示默认上限 N（实现计划定）、主 ID 稳定排序、超额给计数+入口。

## 并发 / 单写者 / 半批恢复
- 锁身份 = 解析后经验目录（同实际库、别名并入）；协作写者、无分布式锁。
- **已审写入计划**：retro 首次写库前持久化（涉 ID / 预期前态 / 目标态 / **预期内容摘要与取代边**），≠完成处置。
- 锁内固定写序：经验文件 → INDEX → 读回核对 → 处置记录；再归档前 lint。
- 恢复：持锁核对计划——**已审目标匹配才跳过、已审前态匹配才继续、否则停下重审**；修 INDEX→读回→补完成记录。归档前拒有计划未结案（限扩展 lint 门禁）。
- 锁超时停止；残锁人工清理。

## 存量软 / 新建硬 + 豁免
唯一入边新硬约束在"本次已审写入计划"内硬检，全量 lint 对旧库只读诊断；豁免截止点=验证任务开始前、留痕、已判拒绝补设。

## 度量
`--report` 原义 + 非执法契约；不引入第二套执法；警示指标独立；坏警示非执法模式不改退出契约。

## 实现计划必验项（3 项 P1，留待硬性验收）
1. **写入边界到文件级**（非仅目录）：仅写实际经验目录内普通文件，拒链接/无法确认归属目标；持锁后写前复核全部目标；writer 与 lint 同判据。验收：目录外跳 + 经验文件外跳 + INDEX 外跳 + 断言未改外部文件。
2. **半批恢复核对已审内容**（非仅状态）：计划对新增文件记"预期不存在"+内容摘要、对更新绑预期变更+取代边；仅匹配才跳过/继续，否则停下。验收：正常半批重启 + "同 ID 同状态但取代边不同"（须留未结案）。
3. **纠错扫描范围含已结案未归档**：同库锁下汇总已归档 **+ 已完成处置的开放 change**；未完成计划阻断同 ID 恢复；每条合格应回灌判定独立成键（零状态 diff ≠ 零处置记录）。验收："只撤一条"拆第二条已归档 / 已结案未归档两组，两组都不得恢复 `active`。

## 决策记录
